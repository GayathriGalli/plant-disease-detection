# 🌿 Plant Disease Detection Using Deep Learning

## 📌 Project Overview

Plant diseases can significantly affect crop health and agricultural productivity. This project uses Deep Learning and Computer Vision techniques to identify plant diseases from leaf images.

The system analyzes an uploaded plant leaf image and uses a trained image classification model to predict the corresponding plant disease.

## 🎯 Objectives

- Detect plant diseases from leaf images
- Apply image preprocessing and augmentation techniques
- Train a deep learning image classification model
- Evaluate model performance on unseen images
- Provide automated disease predictions from uploaded images

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- NumPy
- Pandas
- Matplotlib
- Computer Vision
- Jupyter Notebook

## 🧠 Machine Learning Workflow

1. Load plant leaf image dataset
2. Perform image preprocessing and resizing
3. Split data into training and validation datasets
4. Train the deep learning classification model
5. Evaluate model performance
6. Predict plant disease classes from new leaf images

## 🔄 Architecture

Plant Leaf Image

Predicted Plant Disease
